Scientific Computing – Python Assignments

1. Project Description

This project contains Python assignments completed as part of the Scientific Computing course. It demonstrates the application of Python programming, numerical methods, mathematical computations and data analysis to solve scientific and real-world problems.

In addition to the lecturer-provided assignments, I have created and included my own examples for each task to improve my understanding and demonstrate practical application of the concepts learned.

3. Scientific Computing
4. Gaussian Methods
5. Solutions of Linear Equations
6. Matrix Algebra
7. Iterative Methods
8. Eigenvalues and Eigenvectors
9. Root Finding – Bisection Method
10. Newton-Raphson Method
11. Polynomial Functions
12. Interpolation
13. Numerical Differentiation
14. Random Numbers
15. Optimization
16. Numerical Integration
17. Ordinary Differential Equations (ODE)
